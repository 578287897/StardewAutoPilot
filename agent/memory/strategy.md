# 星露谷自动游玩策略（初始版本，会被每日复盘改写）

## 每日固定流程
1. 早上先 `harvest_crops`，再 `water_crops`（下雨天跳过浇水）。
2. 背包里有农产品就 `ship_produce`（出货箱，次日到账）。
3. 有钱且有空地时买种子种下：春季优先防风草(Parsnip, 20g, 4天)、土豆(Potato)、花椰菜(Cauliflower)；夏季蓝莓(Blueberry)、甜瓜(Melon)；秋季蔓越莓(Cranberries)、南瓜(Pumpkin)。
4. 剩余体力用于 `clear_debris` 清理农舍附近空地，扩大可耕种面积。
5. 体力 < 15 或时间 ≥ 23:00 就 `sleep`。

## 规则
- 皮埃尔商店(SeedShop) 9:00-17:00 营业，周三休息。去买种子要在 17:00 前到。
- 季节最后几天不要种来不及成熟的作物（换季作物会枯死）。
- 种地尽量集中在农舍门口附近，减少走路时间。
- 浇水壶空了宏动作会自动去水边灌水。
- 下雨天：不用浇水，可以去矿洞(Mine)或钓鱼/采集。
- 不要空等商店开门：先做顺路的采集/清理/社交，再在营业时间内去买东西。
- 农场要整齐美观：作物只种在规划好的矩形地块（6x4，地块间留 1 格走道），按行排列；机器、箱子、建筑以后也要成排对齐，放在地块之外。
